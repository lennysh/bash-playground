# Random scripts

Small standalone Bash utilities. Each script has its own markdown file beside it.

| Script | Docs |
|--------|------|
| [`check_podman_image.sh`](check_podman_image.sh) | [check_podman_image.md](check_podman_image.md) |
| [`check_podman_stats.sh`](check_podman_stats.sh) | [check_podman_stats.md](check_podman_stats.md) |

## Adding a script

1. Add `your_script.sh` (executable).
2. Add `your_script.md` with usage, requirements, and examples.
3. Link both in the table above.
4. Keep examples generic — no personal hosts, registries, secrets, or private paths.
